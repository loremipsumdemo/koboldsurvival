Fonts: data/font, packed into data.pak (src/fonts.cpp). Automatic, the default, draws each character in the first
of these fonts that has it, starting with the one that suits the language in use. A font picked in Settings is
tried first, and a basic system font, if one is installed, last. The title's name is drawn from the same fonts.

File	Scripts	First choice for
NotoSans-Regular.ttf	Latin, Cyrillic, Greek, Vietnamese	Every language not listed below
NotoSansArabic-Regular.ttf	Arabic	Arabic
NotoSansJP-Regular.ttf	Japanese	Japanese
NotoSansKR-Regular.ttf	Korean	Korean
NotoSansSC-Regular.ttf	Chinese, Simplified	Chinese (Simplified)
NotoSansTC-Regular.ttf	Chinese, Traditional	Chinese (Traditional)
NotoSansThai-Regular.ttf	Thai	Thai

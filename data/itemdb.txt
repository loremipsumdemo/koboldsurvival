# Item database. One block per item, starting with its id in brackets, e.g. [23].
# Each line is key = value. Text values run to the end of the line. A key left empty means none.
# Blank lines and lines starting with # are skipped. Keys:
#   type              : item, consumable, weapon, armor or accessory
#   max_stack_size    : most of this item one inventory slot holds (at least 1)
#   name              : base name, e.g. Short Sword
#   description       : flavour text shown in the tooltip
#   max_durability    : 0 for not applicable
#   current_durability: durability when made
#   weight            : weight of one
#   buy_value         : price to buy from a vendor
#   sell_value        : price when sold to a vendor
#   required_level   : minimum level to use or equip
#   attack_value      : attack stat, weapons only
#   defense_value     : defense stat, armor and shields only
#   on_use            : right-click script, e.g. health +50; hunger +10; attack +10 for 60s
#   material          : gear material, e.g. Iron. Empty for none
#   tier              : gear tier, 1 or more. Shown after the name as +N. 0 for none
#   equip_slot        : head, torso, legs, feet, accessory, main_hand, off_hand, either_hand, two_hand. Empty for none
#   tags              : optional, comma-separated words that sort the item for props that take only some items:
#                       raw_food (Raw Food Storage, which takes it only if it is not a consumable), water (Water Tank),
#                       ore. Food Storage takes every consumable, the Weapon Rack every weapon, and the Armor Stand
#                       every armor item (shields included).
#   cooks_into        : optional, the id of the item a campfire cooks this one into, e.g. Raw Bear Meat into Cooked
#                       Bear Meat. A campfire takes any item that has one.

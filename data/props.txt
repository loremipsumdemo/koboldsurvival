# Props. Tab-separated. The first row below names the columns, so they can be in any order. Every row is one prop.
# The row order is the order of the Build tab's list. To add a prop, add a row and a model: it needs no code.
# The kinds the code asks for by name (src/props.h) must all be here. Saves name a prop by its key, so keep the key.
#   key        its name in saves and in this table
#   name_key   language key of its name
#   model      file under data/model. A missing model is drawn as a pink square
#   size       size when drawn
#   use        none, storage, occupy, resource, crafting or passive (works by itself from fuel)
#   stat       the skill that works it, or none
#   item       id of the item it makes (data/itemdb.txt). 0 for none
#   input      id of the item it takes, or cookable for any item with a cooks_into. 0 for none
#   workers    how many can work it at once
#   lock_level Lockpicking needed for its lock. 0 for no lock
#   accepts    what it stores: any, raw_food, food, weapon, armor or water
#   fuel_hours hours one fuel item burns
#   alt_item   id of an item it sometimes makes instead. 0 for none
#   alt_one_in 1 in this many times it makes alt_item
#   speed      how fast it is worked
#   rested     Rested an occupant gains per hour. Above 0 makes it a bed
#   comfort    Comfort an occupant gains per hour
#   work_sound sound while worked (key in data/sfx.txt), or none
#   done_sound sound when an item is made (key in data/sfx.txt)
#   emote      emote over a unit using it (key in data/emotes.txt), or none
#   flags      comma-separated, or none:
#                built           new props of this kind are owned by the builder's faction, and are placed as buildings
#                build_anywhere  may be placed outside a claim
#                scatter         a new level places some near the start
#                claims_land     holds its faction's claim
#                burns_corpses   a corpse can be carried into it, and is destroyed
#                destroyed_by_hand  taken down with the right-click menu's Destroy
#                debris          what is left of a destroyed prop: working it clears it
#                seat            an occupant sits
#                cage            an occupant is locked in
#                airship         floats above the ground, and flies its occupants (as many as workers) over any ground; they
#                                can only get off over open ground, and die if it is destroyed with them aboard

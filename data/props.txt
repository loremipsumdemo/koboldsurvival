# Props. Tab-separated. The first row below names the columns, so they can be in any order. Every row is one prop.
# The row order is the order of the Build tab's list. To add a prop, add a row and a model: it needs no code.
# The kinds the code asks for by name (src/props.h) must all be here. Saves name a prop by its key, so keep the key.
#   key        its name in saves and in this table
#   name_key   language key of its name
#   model      file under data/model. A missing model is drawn as a pink square
#   size       size when drawn
#   use        none, storage, occupy, resource, crafting or passive (works by itself from fuel)
#   stat       the skill that works it, or none
#   item       id of the item it makes (data/itemdb.txt). 0 for none
#   input      id of the item it takes, cookable for any item with a cooks_into, or bones for any bones. 0 for none
#   workers    how many can work it at once
#   lock_level Lockpicking needed for its lock. 0 for no lock
#   accepts    what it stores: any, raw_food, food, weapon, armor, water, wood (Wood Logs) or stone
#   fuel_hours hours one fuel item burns
#   alt_item   id of an item it sometimes makes instead. 0 for none
#   alt_one_in 1 in this many times it makes alt_item
#   speed      how fast it is worked
#   rested     Rested an occupant gains per hour. Above 0 makes it a bed
#   comfort    Comfort an occupant gains per hour
#   work_sound sound while worked (key in data/sfx.txt), or none
#   done_sound sound when an item is made (key in data/sfx.txt)
#   emote      emote over a unit using it (key in data/emotes.txt), or none
#   materials  building material its blueprint needs before it can be built: Wood Logs, or for a foundation, wall
#              or door the Iron Ingots or Dragon Crystals picked for it (per tile for an upper floor). 0 places it
#              finished at once
#   build_seconds  seconds of building it needs at Carpentry 1 (per tile for a foundation or upper floor); higher Carpentry is faster
#   slots      a store's slots (12 for most)
#   capacity   the most items a store holds in all, or 0 for as many as its slots fit
#   group      the Build tab's heading it is listed under: claims, crafting, storage, settlement, furniture, cages,
#              vehicles or nature
#   flags      comma-separated, or none:
#                built           new props of this kind are owned by the builder's faction, and are placed as buildings
#                build_anywhere  may be placed outside a claim
#                scatter         a new level places some near the start
#                claims_land     holds its faction's claim
#                burns_corpses   a corpse can be carried into it, and is destroyed
#                destroyed_by_hand  broken with the right-click menu's Break, leaving its item (or bones)
#                debris          what is left of a destroyed prop: working it clears it
#                seat            an occupant sits
#                cage            an occupant is locked in
#                airship         floats above the ground, and flies its occupants (as many as workers) over any ground; they
#                                can only get off over open ground, and die if it is destroyed with them aboard
#                wheelbarrow     its occupant pushes it about in front of them, store and all, and what is in it weighs
#                                nothing on them; attacking or being attacked makes them let go
#                pulled          with wheelbarrow: drawn behind the one pulling it, not pushed in front, and it slows them
#                                to a tenth of their speed unless they are a large animal (a Bear, or a boss)
#                taming          with cage: only an animal (a mob, bosses too) can be put in it, and one inside is tamed in time
#                moves           a vehicle: it goes wherever it is taken while the game runs, so it is drawn apart from the
#                                props that stay put (airship and wheelbarrow imply it)
#                foundation      laid by dragging a rectangle (3 to 64 tiles a side); pieces are built on it once it is done
#                on_foundation   only on a finished foundation tile of the builder's
#                wall_rule       a wall: each one takes the shape (end, straight, corner, tee or cross) and turn that fits the
#                                wall pieces around it, from the models <model>_end, _straight, _corner, _tee and _cross. Blocks walking
#                door            only on a foundation's entrance; strangers can't pass it while it is locked, and pick or smash it
#                ladder          climbs to the upper floor; only once every edge tile of its foundation has a wall or door
#                stairs          3 steps in a row (the tile placed on is the middle one); the bottom step is stepped onto from
#                                any floor tile beside it, the top step is floor of the level above. R turns it while placed
#                rare            a new level scatters only one
#                stall           sells to other factions' units while a shopkeeper mans it (Man Stall task)
#                exterior        goes outside buildings only: never on a foundation or an upper floor
#                upper_floor     a floor at wall height, that units who climb a ladder stand and move on

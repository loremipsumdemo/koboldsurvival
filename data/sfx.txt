# Sound effects. Tab-separated: key, file in the SFX folder, volume slider (interface or effects), when it plays.
# Every key must be listed once. The last column is only a note. A missing file is silent.
# The files are made by tools/make_sfx.py, which writes each sound to the file named here.
# Working sounds play every 1.6 seconds while a unit works a prop near the camera (the Forge's every 3 seconds).

UiClick	ui_click.mp3	interface	Interface: a button or control clicked
Hit	hit.mp3	effects	Combat: an attack lands
Miss	miss.mp3	effects	Combat: an attack misses or is dodged
ItemMove	item_move.mp3	effects	Items: an item moved inside an inventory, or the inventory sorted
UiHover	ui_hover.mp3	interface	Interface: the pointer moves onto a button, menu item or tab
UiBack	ui_back.mp3	interface	Interface: Cancel, Close, Back, or a menu closed
UiError	ui_error.mp3	interface	Interface: refused (locked, already in use, no room, unreachable, skill too low, wrong item)
UiTab	ui_tab.mp3	interface	Interface: a tab changed
UiToggle	ui_toggle.mp3	interface	Interface: a switch or tick box flipped
UiSlider	ui_slider.mp3	interface	Interface: a slider let go
UiMenuOpen	ui_menu_open.mp3	interface	Interface: a right-click menu, item menu or dialog opens
UiSaved	ui_saved.mp3	interface	Interface: the game saved or autosaved
UiLoaded	ui_loaded.mp3	interface	Interface: a save loaded
UiPause	ui_pause.mp3	interface	Interface: the game paused

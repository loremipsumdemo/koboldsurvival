# MAP

Maps you make in **World Generation** (on the title screen) are saved here as `<name>.map`.
A `.map` file is a small text recipe (seed, style and generator settings), not the terrain itself;
the game rebuilds the ground from it when the map is opened.

The game ships with no map: New Game offers to make one from the default settings if this folder has none.
Any `.map` file here shows up in New Game's map choice and in World Generation's Existing Maps.

Levels made for these maps go in [LEVEL](LEVEL).

Plans for the buildings other factions build go in [BLUEPRINT](BLUEPRINT).
